# 🚀 פשפשוק PRO — שכבת השדרוג (v2)

השדרוג נבנה **כשכבה נוספת מעל הקוד הקיים**: לא נמחק ולא שונה אף קובץ לוגי קיים, לא נמחקה אף עמודה ב-DB, וכל הזרימות הישנות ממשיכות לעבוד בדיוק כמו קודם. כל מה שנוסף חי במרחבי שמות נפרדים.

---

## 🌍 1. ריבוי שפות (7 שפות, מלא)

| | שפה | קוד | |
|---|---|---|---|
| 🇮🇱 | עברית | `he` | ברירת מחדל |
| 🇬🇧 | English | `en` | fallback ראשי |
| 🇸🇦 | العربية | `ar` | RTL |
| 🇷🇺 | Русский | `ru` | |
| 🇺🇦 | Українська | `uk` | |
| 🇫🇷 | Français | `fr` | |
| 🇪🇸 | Español | `es` | |

- **זיהוי אוטומטי:** `users.language` ← סשן ← `language_code` של טלגרם ← עברית.
- **שרשרת נפילה:** שפת המשתמש ← אנגלית ← עברית ← המפתח עצמו (אף פעם לא מסך ריק).
- **מה מתורגם:** כל התפריטים, הכפתורים, כרטיסי המודעות, ההתראות, ההגדרות, פרופיל המוכר, הדיווחים ומרכז הבקרה — וגם **מצב המוצר והאזורים** (`src/i18n/taxonomy.js`), בלי לשנות את הערכים שנשמרים ב-DB.
- **תפריט רב-לשוני חכם:** `src/bot/pro.js` בונה אינדקס של כל תוויות התפריט בכל השפות, כך שלחיצה על כפתור בכל שפה — כולל התוויות הישנות — מנותבת לפעולה הנכונה.

**הוספת שפה חדשה (2 דקות):**
```bash
cp src/i18n/locales/en.js src/i18n/locales/de.js   # תרגם את הערכים
```
ואז ב-`src/i18n/index.js`: `const de = require('./locales/de');` והוספה ל-`LOCALES`. זהו — הכפתורים, הבחירה בהגדרות והשידור לפי שפה מתעדכנים לבד.

## 🛡️ 4. הגנות חדשות (אוטומטיות)

`src/services/antispam.js` רץ **לפני** שליחת מודעה למודרציה:
1. מגבלת מודעות יומית למשתמש (ברירת מחדל 5, ניתן לשינוי מההגדרות).
2. מילים חסומות בכותרת ובתיאור.
3. זיהוי מודעה כפולה (אותה כותרת, סטטוס פעיל).
4. חובת תמונה (ניתן לכיבוי).
5. מצב תחזוקה חוסם פרסום חדש.

בנוסף: מנוע ההתראות (`src/services/alerts.js`) לא שולח למוכר עצמו, מכבד `notifications_enabled`, מוגבל ל-200 שליחות בריצה ומדלג על משתמשים חסומים.

## 🗄️ 5. מיגרציית מסד הנתונים

הרץ ב-Supabase → SQL Editor את **`src/db/schema_v2.sql`** (אחרי `schema.sql`).
הקובץ תוספתי בלבד — `add column if not exists` / `create table if not exists`, בטוח להרצה חוזרת.

**עמודות שנוספו:** `users.language`, `notifications_enabled`, `show_phone`, `is_verified`, `is_vip`, `ads_posted_count`, `deals_count`, `last_ad_at`, `home_region` · `listings.is_featured`, `featured_until`, `report_count`, `bump_count`, `share_count`, `currency`, `city`, `expires_at`.

**טבלאות חדשות:** `saved_searches`, `reports`, `admin_audit`, `blocked_words`, `app_settings`, `events`.
**Views:** `v_category_stats`, `v_top_sellers`.

> גם בלי להריץ את המיגרציה הבוט ימשיך לעבוד: שכבת `src/db/extra.js` עוטפת כל שאילתה ומחזירה ברירות מחדל במקום לקרוס. אבל בשביל הפיצ'רים החדשים — הרץ אותה.

## 🔌 7. איך זה מתחבר בלי לשבור כלום

| הוק | מתי רץ | מה עושה |
|---|---|---|
| `localeMiddleware` | כל עדכון | מזריק `ctx.t` ו-`ctx.lang` לכל ה-handlers |
| `guardPublish` | לפני `pv:confirm` הקיים | בודק ספאם; אם תקין — מעביר הלאה (`next()`) לזרימה המקורית |
| *(אחרי `next`)* | אחרי שהמודעה נשמרה | מונה מודעות + אישור אוטומטי אם מופעל |
| `afterApprove` | עוטף את `a:ok:<id>` הקיים | מחכה לפרסום המקורי ואז מפעיל את מנוע ההתראות |
| `tryHandleMenuText` | לפני `onMenuText` הקיים | מזהה תוויות תפריט בכל שפה; אם לא זוהה — נופל חזרה להתנהגות המקורית |

**מרחבי שמות של callbacks:** `p:*` משתמש · `pa:*` אדמין · `pro:*` מצבי טקסט. אין חפיפה עם `cat: cond: price: loc: ph: pv: ed: m: s: sc: sl: res: fav: fv: my: ct: rate: a:` הקיימים.

## ✅ 8. בדיקת תקינות מהירה

1. `/start` → תפריט 9 כפתורים בשפה שלך.
2. `/language` → בחר 🇷🇺 → כל התפריט מתחלף מיידית.
3. `/browse` → 🔥 טרנדים → ניווט בין מודעות עם ⬅️➡️.
4. חיפוש עם סינון → `/alerts` → «שמירת החיפוש הנוכחי» → אשר מודעה תואמת כאדמין → קיבלת התראה.
5. `/panel` → 📈 אנליטיקס → 📤 ייצוא → מקבל `users.csv`.
6. כפתור 🚩 על מודעה → הדיווח מופיע ב-`/panel` → 🚩 דיווחים.
